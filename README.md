### 💬 About me

I'm a **Java developer** who works across the stack, with a focus on **backend systems and Minecraft server infrastructure**. I build software that is not just functional, but **fast, scalable and pleasant to maintain**.

My day-to-day is Paper plugins for **AtlantisRP** and **CoralMC**: shared libraries, database-backed features and tooling that keeps a network running smoothly. Alongside that, I build web interfaces with JavaScript and React, and I use Python and Lua whenever a script is the right tool.

I like turning messy, complicated problems into **simple, elegant solutions**, and then making them fast enough that nobody notices they're there.
